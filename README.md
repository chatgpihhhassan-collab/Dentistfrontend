# 🦷 Dentia — Dental Clinic Workspace (Frontend)

Modern, AI-powered Dental Clinic Management and Interactive 3D Odontogram Frontend built with React, Vite, TailwindCSS, Three.js, and Lucide Icons.

## 🚀 Live Production & Deployment
- **Deployed on Vercel:** Automated CI/CD deployments connected via GitHub repository.
- **Backend API Target:** `https://dentist-api-dev.vitonta.com`

---

## 🛠️ Tech Stack
- **Framework:** [React 19](https://react.dev/)
- **Bundler:** [Vite 8](https://vite.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **3D Graphics:** [Three.js](https://threejs.org/) / `@react-three/fiber`
- **Icons:** [Lucide React](https://lucide.dev/)
- **Routing:** [React Router DOM v7](https://reactrouter.com/)

---

## ⚡ Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```

---

## 🌐 Deploying to Vercel
1. Go to [Vercel](https://vercel.com/) and click **Add New > Project**.
2. Select the repository `chatgpihhhassan-collab/Dentistfrontend`.
3. Framework Preset: **Vite**.
4. Root Directory: `./`
5. Click **Deploy**.
